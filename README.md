# 黄豆仙人

高铁二等座里的 2D 节奏生存小游戏。自动昼夜轮换、随机声音掩护、六个称号关卡、逐关增强的乘客敏感度、累积黄色雾气与本地纪录。

直接用浏览器打开 `试玩.html` 即可离线游玩。也可运行 `node server.cjs`，访问 http://127.0.0.1:4178。

空格或长按黄色按钮释放，松开憋住。P / Esc 暂停。有效释放至少约 0.16 秒，松开计数；10 / 30 / 60 / 80 / 100 / 128 次依次通关，最终解锁黄豆仙人。安静时完成一次释放会被当场抓包，播放卡通打斗后结束；压力满格会窜稀失败，播放独立的失控动画。未解锁称号隐藏名称，通关后揭晓。

运行逻辑验证：`node --test test.cjs`。

源文件位于 `dist/`。画面通过 Canvas 绘制，声音通过 Web Audio 合成，无外部依赖或网络请求。
